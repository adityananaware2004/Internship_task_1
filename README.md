# Study MBBS Abroad - Landing Page

A modern, responsive landing page built with React and Tailwind CSS for international medical education consultancy.

![Study MBBS Abroad](https://images.unsplash.com/photo-1576091160399-112ba8d25d1d?auto=format&fit=crop&q=80)

## Features

- 🎓 Interactive Hero Section
- 🌍 Country Listings with Details
- 📝 Lead Generation Form with Validation
- 📱 Fully Responsive Design
- 📊 Analytics Integration
- ⚡ Fast Loading and SEO Optimized

## Tech Stack

- React 18
- Vite
- Tailwind CSS
- Lucide React Icons

## Prerequisites

- Node.js (v18 or higher)
- npm (v9 or higher)

## Getting Started

1. Clone the repository:
```bash
git clone <repository-url>
cd study-mbbs-abroad
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

4. Build for production:
```bash
npm run build
```
